План постов на неделю — редактируемые исходники.

Сборка из корня репозитория:
python -m pip install -r requirements.txt
python source/posts/build_workbook.py

Результат: pdfs/content-plan-week.pdf.
content.txt — текст шести страниц.
build_workbook.py — верстка, таблицы, пять интерактивных чекбоксов и кликабельный контакт.
SVG-иллюстрации создаются сборщиком и включены отдельно для редактирования.
В папке fonts сохранены шрифты и соответствующие OFL-лицензии.

Вместо заглушки формы используется почта автора Dimitryi7510@yandex.ru.
Поля для ответов заполняются от руки. Пять чекбоксов поддерживают заполнение в PDF.
